    # CodeAlpha_StockPortfolioTracker

A simple interactive Stock Portfolio Tracker built with Python and Streamlit.

## 🚀 Features
- **Price Lookup**: Utilizes predefined stock prices for popular tickers.
- **Dynamic Input**: Easily add and update quantities for stocks.
- **Real-Time Total Calculation**: Instantly computes individual and total investment values.
- **Portfolio Summary Export**: Download portfolio data as a `.csv` file.
